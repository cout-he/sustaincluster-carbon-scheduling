**Goal:** Build an isolated, runnable single-DC research model for carbon deferral/queue risk and IT/HVAC coordination, then run exactly one frozen acceptance matrix.

## Design decisions

- Retain OM `(10000,200,16000)`, OH `(5888,132,16000)`, OL `(11584,312,16000)` and separate Legacy ×5 equivalents. CPU/GPU usage divided by 100, memory GB; no request recovery or deduplication. Keep original arrival, duration and every task position.
- Reference host: 2×32-core Xeon Gold 6338, 256 GiB (16×16 GiB), 4 cores and 16 GiB per host reserved. Select enough hosts for remaining core capacity; GPU hosts carry exactly 4 V100-class 250 W objects. Remaining CPU/memory capacity above quotas is unavailable to tasks but all devices stay powered. R750/R750xa-class hardware, not an OEM-certified exact SKU or Alibaba reconstruction. SMT/placement/VRAM sharing not simulated.
- IT reference watts: CPU 45→205/socket, GPU 25→250/card, DIMM 3→5, other host 50, switch 100/rack, PSU efficiency .94. Manufacturer TDP/board power are reference envelopes, not measured full-load draw. Idle/dynamic, PSU and overhead values are explicit engineering assumptions. Linear utilization response avoids negative marginal power.
- Air-cooled chiller architecture replaces the old cooling tower. A one-node effective inlet/room thermal store obeys `C*dT/dt = IT + supply_fan + envelope - coil`; pump heat enters evaporator; condenser rejects evaporator heat plus compressor/fan electricity. C=500 kJ/K/host, UA=2 W/K/host; uncalibrated assumptions. 60 s explicit integration; 15 min task decisions. No invented CFD offsets.
- Size coil at 1.3×installed design IT electric power; air design rise 10 K; air rho=1.2 kg/m3, cp=1.006 kJ/kg/K. Supply fan dp=500 Pa, eta=.65. Water cp=4.186 kJ/kg/K, rise=5 K, dp=100 kPa, eta=.6. Condenser fan reference electrical power=.02×coil thermal rating, cubic part-load with .2 minimum when on; not the same physical quantity as thermal capacity.
- COP=`clip(.35*T_evap_K/max(10,T_cond_K-T_evap_K),2,8)`; evaporator=supply−5 C, condenser=max(outdoor+10,evaporator+10). This is a reduced-Carnot research surrogate, not a calibrated EnergyPlus chiller. All approaches/efficiencies are declared assumptions. No temperature dependence of IT leakage, no economizer/humidity/water-consumption model.
- Supply actions 18–26 C. Predict next 15 min using current admitted heat/current weather only; filter for inlet peak≤27 C, hard failure threshold 28 C. Fixed 20 C and variable highest-safe 26 C requests share this filter. Unfiltered hot/high-load actions must be capable of violating the limit in engineering probes.
- Read only three preselected Train fragments (May 1 / March 2 / April 4, selected already in A0 by workload pressure, not new power outcomes). Keep causal hourly boundary observations from frozen CI/weather; quarter-hour weather uses previous hour only, removing next-hour interpolation. Inherit documented fixed UTC−7 source basis, not an unverified seasonal correction.
- Fixed evaluation responsibility: 72 hours per 24 h arrival cohort, all on/idle energy included. Final 6 h both cooling rules request 20 C. Record terminal thermal storage; reject paired terminal temperature difference>.05 K. Unfinished tasks remain in denominator and are failures, never silently drained outside the window.
- Policies FIFO, EDF, threshold-FIFO, threshold-EDF. Threshold uses median of observed last 24 h CI after 4 h warm-up; no future CI/April-fitted constant. Defer only if another 15 min respects personal latest start. Capacity failure takes precedence over policy deferral; record separately. Same-sort immediate/threshold comparisons only for deferral attribution.
- Preserve coarse resource accounting: full allocation each started 15 min slot; release first boundary at/after original finish. JCT/deadline use original duration. Explicitly report this granularity approximation; no shortened workload.

## Predeclared acceptance

Software/physics: every workload row retained, no capacity violation/nonfinite/negative power, no unexplained drop with load, first-law absolute step residual≤1e−5 kJ, carbon recalculation error≤1e−7 kg, all workload tasks complete within common 72 h, no inlet>28 C, maximum safe-filtered prediction≤27 C, matched terminal difference≤.05 K. Identical workload hashes across methods; same energy horizon; identical IT component work across same-capacity policies under affine power/full-slot model (tolerance1e−7 kWh). No DMR≤5% acceptance requirement for deliberately stressed OH.

RQ1 evidence: capacity competition occurs, threshold really defers, and at least one same-sort pair changes future burst/competition/DMR; no requirement that threshold saves carbon or always worsens service. RQ2 evidence: unit physics verifies load→IT→heat→HVAC and thermal safety mechanism; integrated fixed/variable cooling changes HVAC energy at identical task schedules/IT energy, with balance and safety preserved. Any unexplained core anomaly means acceptance fails; no algorithm-stage transition then.

## Review focus / execution ledger

Five failure classes pinned in tests: forbidden-role payloads; malformed/duplicate-ID inputs; tasks completing between grid boundaries; no safe cooling action at extreme inputs; unfair terminal thermal storage or unequal evaluation windows.
