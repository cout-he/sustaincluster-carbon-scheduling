# 补充零任务物理参考（运行前登记）

在完成 A/B/C 已登记案例后，额外运行一次 Train 1× 对应真实天气、CI、固定硬件及原功耗模型的零任务参考。开始/结束仍为 2023-05-01 05:00 UTC 至 2023-05-03 14:00 UTC，共 57h；只将新建 FrozenWorkload 的任务元组置空，不编辑原输入。保留物理模型的连续内部状态及空闲积分，核验 CPU/GPU/MEM 占用均为零。

目的仅是量化这一模型规模下的持续空载功耗，不能作为等工作量策略比较，也不能把它与实际任务运行电能的差解释为严格可加的任务边际功耗或碳下界。HVAC 非线性、有状态，负载轨迹及天气可共同影响差额。不得通过修改容量、关机、循环CI或复制天气制造更低参考。

同一只读脚本输出三档 Train 的 duration、原始 slack（deadline−arrival−duration）和 grid slack（latest grid start−arrival）分位数，使用 pandas 纳秒向上取整释放规则；这不是新的实验选择或策略输入。不读取 Validation/Test。
