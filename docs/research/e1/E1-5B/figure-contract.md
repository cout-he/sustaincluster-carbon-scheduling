# E1-5B 图表契约

图表只呈现三个预注册 PPO seed 的训练和 Validation 诊断；不预设 PPO 优于启发式。采用已确定的 Python/matplotlib 后端，定量网格，双栏约 180 mm 宽，7–9 pt 字体，PDF TrueType 可编辑文字及 300 dpi PNG，另存底层小 CSV。

1. 训练曲线：完整 episode 的 Return、真实奖励分项及首次违约数，横轴为实际环境步数。预算尾段单独审计，不伪装为排空 episode。
2. 动作占比：各 seed 的训练采样与 Validation 确定性推理分别计数，完整保留三个动作及所有 seed。
3. 条件动作：只根据决策前当前 CI、过去观测压力和已知紧迫任务分层；报告分母与空层。分层关联不作因果归因。
4. 碳排放–DMR：全部三种启发式与三个 PPO 候选，使用同一任务集合和公共观察终点。资格门槛固定 5%；两轴包含零，标注重叠点，不隐去差模型。

不删掉不利 seed、不画显著性、不将训练回报当作公共窗口排放。二元标志、计数比例和周期时间特征的边界值与连续资源/队列特征饱和分开记录。仅一个训练与一个验证时间窗，图表不能支持独立 Test 泛化结论。所有图表源数据从实际归档及其哈希检查得到，不生成模拟结果替代。
