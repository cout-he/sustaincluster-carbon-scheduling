# E1-5B PPO-v0 训练报告

普通 SB3 PPO 模式选择器已完成真实参数更新；不含任务级学习安全预算或 Shield，不将本报告的 Return 视为论文减排效果。

## 固定数据与实现

三个候选均使用 May 1 05:00–May 3 05:00 UTC 的同一个 2× 合成压力 Train 集合：11,084 个任务，stress seed 510001。CI 阈值为 April 校准的 161.075，SLA multiplier 1.5、容量和 IT/HVAC 公式、默认 E1-5A Reward、40 维在线状态与三个动作全部保持不变。仅 RL 初始化/采样 seed 不同。

SB3 2.9.0 独立安装至本地新运行时目录，未升级原 Conda 核心包。PPO 的 MlpPolicy [64,64]、256 步 rollout、batch 64、10 epoch、lr 0.0003、discount 0.99、GAE 0.95、clip 0.2、entropy coefficient 0 固定于预检查之前。CPU 单 Torch 线程、确定性算法。每个候选 80 个 rollout；每次 reset 新建物理对象，拍内/跨拍保留状态。
