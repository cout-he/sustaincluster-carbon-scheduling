# Figure evidence contract

Backend: Python/Matplotlib, continuing the saved Python preference. All six figures export editable PDF/SVG and PNG300dpi, font>=7pt, plus original small CSV. No invented measurements or significance/error bars from a single deterministic trace.

1. Schematic-led architecture: the candidate is executable, not proven superior. Current-only sensors and frozen Train surrogate are distinct from measured real physical reward. Node/edge CSV specifies the interface chain.
2. Quantitative forecast: report all 1/2/4h forecast errors on the same Train CI (load replication does not yield independent CI samples). Zero cold fallback is checked; forecast labels are offline scoring only.
3. Paired gain: all twelve E1-7A preselected cases, with IT vs total prediction and genuine full-system single-action labels. Their background/horizon differ from predictions, so no universal accuracy claim.
4. Quantitative comparison: all eight preregistered policies, all six load/split scenarios, equal completed work and common observation endpoint per scenario. Carbon and DMR shown separately from zero; development Validation is labelled.
5. Task timeline: deterministic first arrival/ID among Train1.5x tasks whose M0/M2 start differs. Include negative or zero carbon findings; no selection by improvement. Policies have diverging state trajectories, not a single-action causal experiment.
6. Computation: all actual estimator calls and per-step call counts; runtime is profiling metadata excluded from exact scientific replay. No artificial inference speed claim from source-code inspection.

Model/prediction/actual labels stay explicit. Raw large ledgers and CI/weather archives remain private local artifacts; public release carries only small aggregate/source CSV. Automated source/PDF preflight is supplemented by actual six-panel PNG inspection.
