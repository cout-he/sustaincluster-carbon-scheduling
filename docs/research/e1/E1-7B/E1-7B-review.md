# Read-only review and implementation corrections

Three independent component reviews checked forecast/guard, surrogate/gain and Gym integration without editing frozen sources. They confirmed common background/CI/weather/horizon, incremental IT without idle intercept, static HVAC consistent with the actual upstream algebra, sole persistent executor, capacity-first EDF and original reward reuse. They did not certify predictive accuracy or SLA safety.

After train-001 and the complete initial regression suite finished, tests first reproduced and then fixed: floating duration/real nanosecond release mismatch; positive duration quantized to zero still occupying one real interval; same-pass zero-quantized running occupancy; explicit non-Train role labels; float normalization of the moderate threshold; and guard refusal being incorrectly classified as estimator failure. Prediction attempt and valid-estimate counts are separately labelled. Prehistory now checks the registered raw-source SHA, requires an increasing timestamp prefix and stops parsing at the window boundary. It does not parse subsequent Test rows. Full source-container hashes are provenance identities, not Test episode analysis.

Pre-review source is retained in source-v1.0; old outputs and logs are not overwritten. None of the three registered Train task sets has an occupied-slot mismatch at the corrected edge. calibration-003 versus calibration-002 has identical model parameters, threshold 0.030622302469263302kgCO2e, input identities, prehistory hashes, fit report, forecast scores and ALL 15376 actual EDF-candidate opportunity rows byte for byte (review-hardening-identity.json). The source SHA changes and is recorded; no scientific parameter was selected using development Validation.

The new causal prehistory reader is for the registered chronological hourly source. Arbitrarily unsorted files are outside its contract; disorder within the consumed prefix fails. The source has no missing prehistory. The shield/guard remains a heuristic, and omitted pending starts/future arrivals mean that known-running capacity feasibility is not a guarantee of actual start after fifteen minutes.

Remaining model limits: descriptive IT coefficients are not causal task power; quadratic HVAC derivatives can extrapolate poorly outside Train weather/load; rank is not predictive/causal validity; preview gain is computed before an EDF pass while actual decisions see preceding real starts; total policy differences are not single-event causal effects.
