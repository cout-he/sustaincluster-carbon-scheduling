# Train功率代理：拟合、域与局限

IT仅Train1x EDF公共57h的228拍；HVAC使用Train三倍率三外部基线2052拍，样本高度相关，不作独立统计推断。物理公式没有修改，真实测量不是代理输出。IT截距=481.742194826793kW；CPU/GPU/MEM系数分别为[0.006057597263255481, 0.20170296669591486, 0.00030406553348940197]，单位kW/core、kW/GPU、kW/GB，全部非负。它们是描述性回归系数，不是任务因果功率。

IT秩4、条件数22.663，RMSE=3.163229kW。HVAC秩5、条件数558.040；输入真实IT的样本内RMSE=35.330500kW；串联IT预测后RMSE=39.871764kW。设计矩阵满秩不证明物理可辨识或任务增量可靠。

HVAC五系数=[709.3680732899232, -1639.1563994606395, 2632.9607986899114, -3776.389081637319, 5897.080879538983]；alpha0、tail0；cap=7060.462433kW，为Train最大真实HVAC四倍。IT拟合域[477.4531333333336, 906.5416686268776]kW，天气域[9.2, 14.9]C。域外只标记，不依据Validation临时换模型或阈值。当前天气是原固定输入的UTC线性重采样，不是原生15min实测；未来预测持续当前值。湿球仍为上游0.9*温度变换，物理有效性边界保留。

Train天气较窄，开发Validation存在明显域外和误差增加；HVAC对低IT/温度的回归偏导可能没有物理单调性约束，不能由非负截断声称高保真。`power-domain-clipping.csv`区分实际占用输入的截断、假想idle探针；它不是逐候选未来分支的clip计数。拟合时clipped=0；观察到的48组实际占用输入负/上限截断总数为0/0。

两分支功率推演均为轻量代理，从不调用真实UpstreamPowerModel.measure试探未来。共同背景不包括pending填补和未知到达，可能高估闲下来的未来背景。绝对功率RMSE不等于差分收益误差；预测启动+15也可能由于再次主动等待/容量竞争偏离。
