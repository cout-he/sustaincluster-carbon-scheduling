## 科学解释核查

| 风险 | 本轮处理 |
| --- | --- |
| 假独立/伪重复 | 16同源轨迹片段；压力/SLA/容量/规则复制不当独立实测 |
| 分组选择偏差 | 固定全1440计划，不按DMR或CI代理跳过；失败片段保留 |
| 多重比较与显著性 | 只做描述统计，无显著性检验或胜负宣称 |
| 相关当因果 | 容量等待且违约为交集，不称单独容量因果效应 |
| 构念误替 | observed usage不当reservation，CI代理不当碳排，GPU等价不当实体卡 |
| 聚合掩盖 | 同时报总体DMR、最坏片段及超5%片段数 |
| 分母混用 | 任务/片段/15min槽分开，实际Duration与ceil占用CI分开 |
| 时间泄漏 | 当前CI上一小时左持有；继承April阈值的时序限制披露，不拟合保留集 |
| 事后定配置 | 先定义A0候选和单位重推，再跑固定规则；推荐尚未最终冻结，无RL结果 |
| 缺失/异常数据粉饰 | 不重洗、不删任务；原始请求字段缺失和历史预处理局限明确保留 |
| 不当外推 | 软件可复现不等于真实机房已校准；没有推出算法不可能性或真实节碳 |
