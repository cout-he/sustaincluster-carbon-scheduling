# A0 图表与统计口径

- 后端：已保存偏好Python，matplotlib；不生成模拟结果填充缺失实验。
- 核心问题：展示当前对象的资源争用、可等待性和CI机会，并揭示物理模型是否能支持可信的优化结论。
- 证据结构：资源图比较三个压力档位的逐资源峰值/阻塞/DMR；碳图比较完整任务CI机会和容量可执行规则；物理图展示setpoint响应与18/22交叉及分项来源。
- 图型：quantitative grid。每面板必须对应一个不同的问题，标注实际n和分母，不把96增强视为96独立采集。
- 不做显著性检验或因果泛化；跨场景差异仅描述性。中心/范围或每点含义在图注说明，非独立数据不伪造置信区间。
- 输出PDF/SVG及600dpi PNG预览；字体7pt、面板标签8pt，最小5pt；保留矢量文字。
- 来源：仅本轮真实聚合CSV。未完成部分保留缺失，不插值、不补造实验。
- 手工物理输入明确标记，不作为实测任务数据或经过校准的机房性能。
- 最终执行source validator、PDF文本字号审计和整图视觉检查；结果记入QA。
